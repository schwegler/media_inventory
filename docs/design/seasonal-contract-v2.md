# Shared seasonal contract v2

`config/seasonal.json` supplies the server helper and Stimulus controller. It exposes `window.SchwegSeasonalConfig` with schemaVersion 2, invitationDelayMs, profile, and dated seasons. Trove optionally pins activeSeason. Enabled seasons require approved PNG art and a current inclusive `from` / exclusive `until` window. Date-only boundaries mean UTC. Halloween is explicitly 18 October–1 November 2026 UTC, with no annual recurrence. Christmas is disabled and has no asset; approved artwork and palette are required before enabling it.

The invitation is a small fixed PNG character overlay after one settled-page 1000ms timer. It adds no layout height and does not activate a theme on display. Native keyboard/touch buttons provide activation and a 44px dismiss target. Only controls intercept input. Placement chooses among viewport-edge positions using measured navigation, alerts, dialogs and primary controls on show, resize, scroll and focus; event work is animation-frame throttled, never polled. Open modal dialogs hide the overlay. Safe edges and a generous bottom reserve protect mobile browser controls.

Click applies dark Halloween with orange accents, a CSS atmosphere, a compact alert and Undo. Snapshot restoration includes exact missing/present root attributes. `seasonal-theme:v1` stores `halloween` / `off`; `seasonal-motion:v1` stores `paused` / `auto`; `sessionStorage` key `seasonal-prompt:v1:halloween-2026` dismisses per tab. Trove additionally stores its exact previous appearance and account preference signature in `trove-seasonal-session:v2:halloween-2026`. Account changes invalidate that session. Root data-season, data-season-id and data-season-motion and the `schweg:seasonal-change` event match the shared contract. Event detail: schemaVersion, seasonId, theme, active, motion, source.

OS reduced motion and saved reduced effects disable animation; pause makes movement static; Hide atmosphere removes the scene. Footer On/Off/Reset/Pause controls remain available. One deadline timer removes seasonal state at the exclusive boundary. No polling, canvas animation, remote dependencies or eager image collection loads.
